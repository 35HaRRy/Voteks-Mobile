# Voteks-Mobile

## Overview
An Android application for the Voteks mobile experience.
The project is built with the Android Gradle toolchain and includes a backend module alongside the app module.

## Dependencies
- Android Studio
- Android Gradle Plugin 2.2.x
- Android SDK API 24
- AppCompat support libraries
- Local JAR dependencies in `app/libs`

## Setup
1. Open the project in Android Studio.
2. Let Gradle sync the project and download the declared dependencies.
3. Make sure the local JAR files in `app/libs` are present.
4. Update any app-specific configuration before running.

## Run
- Run the `app` module from Android Studio.
- Build and install the APK on an emulator or device.

## Notes
This is an older Android project, so you may need an older Android Gradle Plugin and SDK setup to build it successfully.
